Serverless cloud financial management bot automating multi-cloud waste elimination, VM rightsizing, and non-production scheduling.

---

## 📈 Proven Financial Impact
- **32% Annual OPEX Reduction:** Purges orphaned managed disks, unassociated public IPs, and obsolete snapshots.
- **Automated Workload Scheduling:** Shuts down non-production Dev/UAT environments outside business hours, saving 65% compute cost.
- **Infracost PR Guardrails:** Enforces hard budget failure gates directly inside GitHub Actions Pull Requests.

---

## 🚀 Execution & Quickstart

```bash
# Clone repository
git clone https://github.com/Bhawesh-DevOps/cloud-finops-sentinel.git
cd cloud-finops-sentinel

# Run FinOps audit CLI
python main.py
```
